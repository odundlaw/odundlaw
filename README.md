### About me

I'm a software engineer who builds reliable, production-grade web applications and backend systems. I have several years of experience across **enterprise security software, fintech, Web3 and business platforms**, and I've worked on every part of a product, from database design and APIs to polished frontends and cloud infrastructure.

I care about clean architecture, correct data models and software that holds up under real use.

### What I do

- **Backend engineering:** REST and GraphQL APIs, microservices, authentication and SSO, payment flows, and data integrity enforced in the database
- **Frontend engineering:** fast, accessible React applications with solid state management and good UX
- **Browser and security software:** Chromium-based browser features, browser extensions and identity-provider integrations
- **Fintech and Web3:** escrow and transaction systems, payment-instruction processing, blockchain token analysis services
- **Business platforms:** booking and scheduling systems, invoicing and deposits, admin dashboards, learning platforms
- **Infrastructure:** containerised services, infrastructure as code and Linux environments
